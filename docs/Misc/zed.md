# Zed

## キーバインド

| key map                | command                           |
| ---------------------- | --------------------------------- |
| ctrl + Shift + p       | コマンドパレット                  |
| Ctrl + Alt + Shift + o | リモート接続                      |
| Ctrl + r               | 最近開いたプロジェクト/ウィンドウ |
| Alt + Shfit + f        | 選択部分を整形                    |

## Remote SSH

`Ctrl + Alt + Shift + o`でopen remoteが起動。  
「Connect SSH Server」で接続先情報を入力。
